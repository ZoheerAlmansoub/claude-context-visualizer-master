# Screenshots for README

Do **not** commit screenshots that show real session titles, project paths, API keys, or private transcript content.

## Safe options

1. **Empty state** — landing screen before selecting a session (no sidebar entries visible).
2. **Fixture data** — use `server/fixtures/` sessions only, on a machine with no personal transcripts indexed.
3. **Redaction** — blur or crop project names and message text before committing.

## Suggested files (optional)

| File | Content |
|------|---------|
| `context-treemap.png` | Context tab with fixture session |
| `analysis-panel.png` | Analysis cards (no private text) |
| `governance-pipeline.png` | Pipeline UI (generic state) |
| `session-sidebar.png` | Sidebar with fixtures or empty state only |

If unsure, skip screenshots in the README — the project docs are sufficient without them.
